## Four cases and required outcomes

| Case               | Supplied material                                                                                                                   | Required outcome                                                                                                                                      |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| Verified reference | Repaired source; complete passing project, behavior, focus, readability and visual evidence                                         | REVIEW PASS after source, local Salt and actual image inspection, with no unsupported blocker                                                         |
| Navigation defect  | Reference with only the known custom primary-navigation replacement; equivalent complete evidence                                   | CHANGES REQUIRED, establishing the available Salt navigation coverage and identifying the custom replacement as an actionable task defect             |
| Clipping defect    | Reference with only the known detail-column clipping; complete behavior evidence plus actual failed readability evidence and images | CHANGES REQUIRED, identifying clipped saved content from the supplied evidence; a passing behavior check must not erase the failed readability result |
| Missing evidence   | Reference source and one desktop image, with mandatory project/runtime evidence explicitly absent                                   | INCOMPLETE and no overall approval                                                                                                                    |

The navigation and clipping cases are separate so finding one does not conceal
failure to assess the other. The clipping case supplies its failed check
truthfully; success on it therefore assesses review of combined source, images
and machine evidence, not unaided visual detection. Custom definition-list
content or a disclosure action inside DialogContent is not itself a defect.
Use the actual task and installed contract to distinguish a coverage gap from
an optional alternative. If a genuine previously unknown reference defect is
found, preserve the result, invalidate its expected-pass label and diagnose it;
do not reinterpret that finding as a false positive to claim qualification.
