Fixed bordered `ToggleButton` hover and pressed styling. A bordered toggle button now uses the actionable hover border and the actionable active background, border and foreground when pressed, so pressing it shows visible feedback.

A selected standalone `ToggleButton` now uses the actionable bold hover foreground on hover, and a selected positive solid `ToggleButton` now uses the positive hover background instead of the accented one.
