Added `--salt-target-borderColor` to all themes, for the border of a target or target marker in its default state, showing where an item can be dropped or placed. Use it with a dashed border style.

```css
border: var(--salt-size-fixed-200) var(--salt-borderStyle-dashed)
  var(--salt-target-borderColor);
```
