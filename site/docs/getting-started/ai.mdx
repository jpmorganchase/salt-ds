Salt's AI-focused developer tooling has not been released.

There is currently no supported Salt AI package, CLI, MCP server, installation
command or compatibility contract for consumers. Source code and experiments
in this repository are pre-release implementation work and must not be treated
as published product documentation or as a supported integration.

Use the ordinary [Developing with Salt](./developing) guide, package READMEs and
the public component and pattern documentation today. Those resources are the
supported way to install Salt, choose the current provider and theme, and build
consumer applications.

This page will be replaced with installation and usage guidance only after the
tooling and its public delivery architecture have been released and verified.
