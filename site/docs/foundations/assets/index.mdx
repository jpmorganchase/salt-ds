Salt icons communicate actions, objects and concepts through open geometry, crisp terminals and selective curves. Use a familiar icon consistently, and pair it with a visible label when its meaning needs explanation.

Browse the catalogue below to choose an icon. The [icon design guidelines](/salt/foundations/assets/icon-design) describe the family’s visual language, and [Creating icons](/salt/foundations/assets/creating-icons) explains how to contribute artwork and integrate it into Salt.

## Icon variants

Icons are available as **outline** and **solid** variants. Available variants depend on the icon. Both preserve the same meaning and defining features. Choose a consistent treatment for related controls; solid does not imply a selected state unless that relationship is established in the interface.

Outline icons use open space to keep their visual weight light. Solid variants introduce filled surfaces to provide greater emphasis, while retaining the open lines needed to describe the shape or action. Choose the variant that fits the surrounding interface and use it consistently.

## Scaling icons

Icon size will vary based on use case and system requirements. Standard sizing ensures components maintain a consistent spatial relationship with surrounding elements.

Icons share a 16 × 16 canvas and preserve their natural proportions. Judge their apparent size beside surrounding text and controls. See [Canvas and optical size](/salt/foundations/assets/icon-design#canvas-and-optical-size) when designing new artwork.

Use the density's default size for icons within controls. A size multiplier can give a standalone icon more emphasis; check that its weight and spacing remain balanced with the surrounding content.

<IconDesignExamples example="scale" />

| Size token         | Multiplier | High Density (HD) | Medium Density (MD) | Low Density (LD) | Touch Density (TD) |
| ------------------ | ---------- | ----------------- | ------------------- | ---------------- | ------------------ |
| `--salt-size-icon` | x1         | 12 \*             | 12                  | 14               | 16                 |
|                    | x2         | 20                | 24                  | 28               | 32                 |
|                    | x3         | 30                | 36                  | 42               | 48                 |
|                    | x4         | 40                | 48                  | 56               | 64                 |

\* Icons have a minimum size set at 12px and should not be displayed any smaller. For high density this means the default size of an icon is 12px, but the rest of the scale grows based on small base dimension.

### Icon sizing when paired with display and heading text

- Match the icon container height to the text line-height.
- Match the icon glyph size to the text font-size.

When an icon is paired with **display** or **heading** text styles, the icon size (i.e., the glyph) is aligned with the text size, and the icon’s container is aligned with text line height.
Check the visual alignment with the first line when the text wraps.

## Stroke weight

Use the density's default stroke weight so icons fit surrounding text and controls. Generated React icons use **4/3 units in high and medium density**, **8/7 units in low density**, and **1 unit in touch and mobile density**. This gives an approximately 1 CSS-pixel primary stroke at each density's default icon size: 12px, 14px and 16px respectively. Larger size multipliers scale the stroke with the icon.

<IconDesignExamples example="stroke" />

Use `--salt-size-icon-strokeWidth` for an application or subtree, or `--saltIcon-strokeWidth` for an individual icon. The fallback is 1 when neither variable is defined. Secondary strokes keep their proportions; filled contours keep their geometry. Review any override at the intended size, including internal gaps and sharp tips. See [Icon stroke width](/salt/foundations/size#stroke-width) for settings and examples.

Standalone SVGs and the CSS masks in `saltIcons.css` retain their baked 0.67-unit reference strokes and do not inherit these variables. Check the chosen rendering format in context. For artwork decisions, follow [Stroke weight](/salt/foundations/assets/icon-design#stroke-weight).

## Accessible use

Give an icon an accessible name when it communicates information on its own. If adjacent text already conveys the meaning, hide the icon from assistive technology with `aria-hidden`. For an icon-only button, give the button an accessible name and treat its icon as decorative. See the [Icon component](/salt/components/icon) for implementation examples.

## Spacing between icon and text

Spacing between an icon and its paired text varies by context. The sub-sections below cover key scenarios.

### When to use spacing-50

Use `--salt-spacing-50` between an icon and text within compact controls, including:

- [Button](/salt/components/button)
- [Toggle button](/salt/components/toggle-button)
- [Pill](/salt/components/pill)
- [Tag](/salt/components/tag)

- [Dialog](/salt/components/dialog)
- [Tooltip](/salt/components/tooltip)

### When to use spacing-100

Use `--salt-spacing-100` for icons beside labels in repeated or stacked elements, including controls with nested content. This also applies to checkbox and radio labels:

- [Accordion](/salt/components/accordion)
- [Vertical navigation](/salt/components/vertical-navigation)
- [Tabs](/salt/components/tabs)
- [Tree](/salt/components/tree)
- [List box](/salt/components/list-box)
- [Menu items](/salt/components/menu)
- [Checkbox](/salt/components/checkbox)
- [Radio button](/salt/components/radio-button)

### Spacing between icon and heading/display text

<Callout status="info">
  Heading spacing is experimental. Existing components may retain their own
  spacing, including Dialog. Follow the component guidance when using those
  components, and [share feedback](/salt/support-and-contributions/index) on
  this heading treatment.
</Callout>

For editorial and marketing layouts, use the following spacing with heading and display text. Check the icon size and text alignment together. Within an existing component, follow its spacing guidance.

| Heading/Display text | Spacing between Icon & Text |
| -------------------- | --------------------------- |
| Display1, Display2   | `--salt-spacing-300`        |
| Display3, Display4   | `--salt-spacing-250`        |
| H1, H2               | `--salt-spacing-150`        |
| H3, H4               | `--salt-spacing-100`        |
