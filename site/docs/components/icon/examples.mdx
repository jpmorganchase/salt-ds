## Basic icon

Import the icons you need from `@salt-ds/icons`.

## Icon size

You can change the size of each icon using the `size` property, which acts as a multiplier for the base icon’s size, as described in the [icon foundation](/salt/foundations/assets). The base size of the icon depends on the active density as described in the [size foundation](/salt/foundations/size).

<LivePreview componentName="icon" exampleName="IconSize" />

## Icon types

Outline and solid variants preserve the same meaning while changing visual emphasis. Availability varies by icon. Use a consistent variant for related controls; use an outline/solid change for selection only when the interface makes that state relationship clear. See [Icon variants](/salt/foundations/assets/index#icon-variants).

<LivePreview componentName="icon" exampleName="IconTypes" />

## Icon color

To override the default color of the icon, use the `color` prop. This allows you to set the color to `primary`, `secondary` or `inherit`.

<LivePreview componentName="icon" exampleName="IconColor" />

## Custom icons

If you need a custom SVG icon, use the `Icon` component. `Icon` has the same API as the native `<svg>` element. Follow the [icon design guidance](/salt/foundations/assets/icon-design), provide the SVG viewBox, and label the icon when it conveys information on its own. Use `aria-hidden` for decorative artwork or when the containing control already has an accessible name.

<LivePreview componentName="icon" exampleName="CustomIcon" />

## Custom colors

If you need to use a color other than "primary" or "secondary", use `color="inherit"` or use CSS to change the icon's `fill`.

<LivePreview componentName="icon" exampleName="CustomColors" />

## CSS background image

Import `@salt-ds/icons/saltIcons.css` and use the icon class, such as `saltIcons-AddDocument`, to display a CSS mask. These assets retain baked stroke widths and do not inherit React stroke settings. Provide any accessible name on the containing element.
