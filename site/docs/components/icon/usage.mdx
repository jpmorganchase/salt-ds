## Using icons

Use an icon to support recognition of an action, object or state. Choose a familiar symbol and use it consistently. Add visible text when its meaning may be unfamiliar or depends on the application; icons are not universally understood across languages and contexts.

Use the density's default size and weight within controls. Keep related icons consistent in variant, apparent size and spacing. A solid variant can provide emphasis, but does not automatically communicate selection.

An icon is a visual element. For an action, place it inside a [Button](/salt/components/button) or another appropriate interactive component. Give an icon-only control an accessible name that describes the action.

Browse the [icon catalogue](/salt/foundations/assets/index), follow the [design guidance](/salt/foundations/assets/icon-design) for custom artwork, and see [accessible use](/salt/components/icon/accessibility) for labels and decorative icons.

## Import

Import individual icons from the package:

```js
import { AddDocumentIcon } from "@salt-ds/icons";
```

Use the `Icon` component to render custom SVG artwork:

```js
import { Icon } from "@salt-ds/icons";
```
