## Status

Use the `status` prop to change the displayed status. This will affect both
the icon and the color of `StatusIndicator`. The status indicator offers
four severity levels that set a distinctive indicator and color.

<LivePreview componentName="status-indicator" exampleName="Status" />

## Size

You can control the size of the Status Indicator with the `size` prop. This
number will multiply the base size as described in the
[size foundation](/salt/foundations/size).

<LivePreview componentName="status-indicator" exampleName="Size" />

## With text

Pair a status indicator with concise text when a status needs visual emphasis in
a compact, inline layout. The text should communicate the complete status
without relying on the indicator or its color.

For a status that replaces content in a container, or needs a title, supporting
message or action, use the [content status
pattern](/salt/patterns/content-status).
