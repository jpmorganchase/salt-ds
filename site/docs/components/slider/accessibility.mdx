## Best practices

- Give the `Slider` an accessible name. Wrap it in a [`FormField`](/salt/components/form-field) with a `FormFieldLabel`, or set the `aria-label` or `aria-labelledby` prop.
- Screen readers announce the current value and describe the range, for example, "range minimum 0, maximum 100". If `step` isn't 1, the description includes the increment. If `restrictToMarks` is `true`, it includes "custom increments".
- If you set custom `minLabel` and `maxLabel` text, set `accessibleMinText` and `accessibleMaxText` so screen readers announce the same text. Refer to the [labels example](/salt/components/slider/examples#labels).
- Use the `format()` callback to announce values with units or currency. For non-numeric values, also set `aria-valuetext`. Refer to the [example with non-numeric values](/salt/components/slider/examples#with-non-numeric-values).
- The tooltip is visual only. Screen readers announce the value from the `Slider` itself.

## Keyboard interactions

<KeyboardControls>
<KeyboardControl keyOrCombos="Tab">

- If focus is outside the `Slider`, moves focus to the thumb.
- If focus is on the thumb, moves focus to the next component in the tab order.
- If the `Slider` is disabled, it's skipped.

</KeyboardControl>

<KeyboardControl keyOrCombos="Shift + Tab">

- Moves focus to the previous component in the tab order.

</KeyboardControl>

<KeyboardControl keyOrCombos="Up arrow / Right arrow">

- Increases the value of the thumb by one step. If `restrictToMarks` is `true`, moves it to the next mark.

</KeyboardControl>

<KeyboardControl keyOrCombos="Down arrow / Left arrow">

- Decreases the value of the thumb by one step. If `restrictToMarks` is `true`, moves it to the previous mark.

</KeyboardControl>

<KeyboardControl keyOrCombos="Home">

- Sets the thumb to the first allowed value.

</KeyboardControl>

<KeyboardControl keyOrCombos="End">

- Sets the thumb to the last allowed value.

</KeyboardControl>

<KeyboardControl keyOrCombos="Page Up">

- Increases the value of the thumb by `step` multiplied by `stepMultiplier`, which defaults to 2. If `restrictToMarks` is `true`, moves it to the next mark.

</KeyboardControl>

<KeyboardControl keyOrCombos="Page Down">

- Decreases the value of the thumb by `step` multiplied by `stepMultiplier`, which defaults to 2. If `restrictToMarks` is `true`, moves it to the previous mark.

</KeyboardControl>

<KeyboardControl keyOrCombos="Escape">

- Hides the tooltip displayed when hovering over the thumb.

</KeyboardControl>

</KeyboardControls>
