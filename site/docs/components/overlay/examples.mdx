## Default

The `Overlay` component allows the user to expose and interact with supplemental information. The overlay remains persistent until the user dismisses it.

<LivePreview componentName="overlay" exampleName="Default" />

## Placement

Use the `placement` prop to position overlay content to the `top`, `bottom`, `left` or `right` of the trigger element.

<LivePreview componentName="overlay" exampleName="Placement" />

## Sections

Use `OverlayHeader`, `OverlayPanelContent` and `OverlayFooter` to create distinct padded sections within `OverlayPanel`. Sections need to be direct children of `OverlayPanel` so their spacing rules apply; adjacent sections share a single `--salt-spacing-100` gap.

`OverlayHeader` follows the [Header Block pattern](/salt/patterns/header-block). Pass the title to `header`, and add `preheader` or `description` when needed.

<LivePreview componentName="overlay" exampleName="WithSections" />

## Long content

When content in `OverlayPanelContent` extends beyond its set height, it scrolls while the header stays in place.

## With actions

With actions, users can decide if interacting with content in the overlay should close the overlay. This example shows how activating the **Export** button triggers the export function, closes the overlay, and returns focus to the trigger element.
