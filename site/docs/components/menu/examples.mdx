## Multilevel

Menus can contain submenus which present the user with a set of items to interact with, creating a cascading effect.

### Best practices

- Creating submenus as separate components will allow you to reuse them in different parts of your application and make your code more maintainable.
- Limit the number of levels in your menu to avoid overwhelming users.

## Single selection

Set `selectionVariant` to "single" on a `MenuGroup` to let users choose one option from a set, such as a sort order. Give each `MenuItem` a unique `value`, and give the group a `name` so it keeps the selection while the menu is closed. Set the initial selection with `defaultSelected`. Each item shows a radio button, and clicking an item selects it and closes the menu.

### Best practices

- Give each group a `name` that's unique within the menu, so a group doesn't reopen with another group's selection.

<LivePreview componentName="menu" exampleName="SingleSelection" />

## Multiple selection

Set `selectionVariant` to "multiple" to let users turn several options on or off, such as the visible columns of a table. Each item shows a checkbox, and clicking an item toggles it and keeps the menu open, so users can change several options at once.

To change whether clicking an item closes the menu, set `closeOnSelect` on the `MenuGroup`.

<LivePreview componentName="menu" exampleName="MultipleSelection" />

## Selection with actions

A menu can combine single selection, multiple selection and actions. Place each set of options in its own `MenuGroup`, and put actions in a separate `MenuGroup` without a `label`.

This example controls the selection with the `selected` and `onSelectionChange` props, so the Reset view action can change it.

### Best practices

- Keep actions out of selectable groups, so each group contains one kind of option.
- When you control the selection, keep the state outside the `Menu`, for example in the component that renders it. The menu's content unmounts when the menu closes, so state stored inside it resets.

<LivePreview componentName="menu" exampleName="SelectionWithActions" />

## With icon

Icons can be used to help users quickly identify the type of action they can take.

### Best practices

- Icons should be displayed before a menu item label.
- Use icons consistently across all menu items within the same group.

## Placement

Placement of the menu can be specified using `placement` prop. The menu will be positioned relative to child of the `MenuTrigger` component.
By default, the root menu is aligned to the "bottom-start" of the trigger element and submenus to the "right-start" of the parent menu item.
