## Using the component

### When to use

- When typing would help users find and select from available choices, and the full list does not need to stay visible.
- When a workflow benefits from a filter that narrows the available options. The application supplies the filtering logic and rendered options.
- For single or multiple selection from a popup. Use `multiselect` when multiple values are allowed.

### When not to use

- When users can find the options without typing and a popup is appropriate. Instead, use [`Dropdown`](../dropdown).
- When a small, mutually exclusive set of choices should remain visible together. Instead, use [`RadioButtonGroup`](../radio-button).
- When multiple independent choices should remain visible together. Instead, use [`CheckboxGroup`](../checkbox).
- When a selectable list should remain visible. Instead, use [`ListBox`](../list-box).
- For a popup list of actions such as Edit or Delete. Instead, use [`Menu`](../menu).
- For an on/off setting that takes effect immediately. Instead, use [`Switch`](../switch).

See [Choosing a selection control](../list-box/usage#choosing-a-selection-control).
An option count alone does not determine the control, and `ComboBox` does not
automatically filter or virtualize a large list.

### Controlled/Uncontrolled

By default, a combo box manages its own input text and selection. Use
`defaultValue` for the initial input text and `defaultSelected` for the initial
selection.

Use `value` with `onChange` to control the input text, and `selected` with
`onSelectionChange` to control the selection. When controlling the input text, also
update it from `onSelectionChange`: show the chosen label for single selection or
clear the search text after multiple selection, as the [examples](./examples)
demonstrate. These are separate values; see
[Filtering and submitted values](../list-box/usage#filtering-and-submitted-values)
before connecting the control to form submission.

## Import

To import `ComboBox` from the core Salt package, use:

```js
import { ComboBox, Option, OptionGroup } from "@salt-ds/core";
```
