## Open in a new tab

Use `target="_blank"` with `rel="noopener"` or `rel="noreferrer"` to open a link button in a new tab. See [usage](./usage) for when to choose this behavior and [accessibility](./accessibility) for how the new-tab cue is announced.

## Underline

Link buttons are underlined by default to indicate that they navigate to another destination. Use `underline="never"` only when this is already clear from the surrounding context and does not rely on color alone.

<LivePreview componentName="link-button" exampleName="Underline" />

## With icon

Link buttons support both leading and trailing icons. In most cases, use a trailing icon to reinforce the destination or direction of travel, such as `ArrowRight` or `TearOut`, to indicate moving forward or leaving the current context.

An exception is backward navigation. Use a leading icon such as `ArrowLeft` to indicate returning to a previous page or step. You can also use a leading icon when it acts as a clear visual identifier for the label.

<LivePreview componentName="link-button" exampleName="WithIcon" />

## Icon only

Use an icon-only link button when space is limited and the icon clearly communicates the destination or direction of travel. This can be a directional icon, such as a back arrow; a brand icon, such as the GitHub logo; or an icon familiar in your product context, such as a basket in a commerce application or a wallet in a finance application.

See [accessibility](./accessibility) for accessible naming, decorative icon, and tooltip guidance.
