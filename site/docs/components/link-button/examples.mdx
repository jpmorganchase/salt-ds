## Neutral

The neutral link button is ideal for routine, lower-emphasis navigation that requires less visual prominence on the page. Use it when the destination is useful but not the primary call to action.

## Open in a new tab

Use `target="_blank"` to open the target page in a new tab. A tear-out icon that communicates this to the user will display next to the link button.

Avoid opening links in a new tab unless there is a clear user benefit. Opening a link in a new tab is not expected default behavior for web browsers. It makes it harder to return to the previous page, especially for users of screen readers.

Recommended cases include link buttons in the middle of a form or multi-step process. This allows users to complete the action without losing their place on the original page.

Keep the default icon for standard text link buttons. Use `IconComponent={null}` only for composed or custom content that already provides a separate visible cue that the link button opens in a new tab. Avoid hiding the icon when there is no other visible cue.

### Security

When linking to third-party content, we recommend setting `rel="noopener"` or `rel="noreferrer"`. Although this is default behavior in newer browsers, explicitly specifying this helps protect users of legacy browsers. For more information, read [Links to cross-origin destinations are unsafe](https://web.dev/external-anchors-use-rel-noopener/).

## Underline

Prefer the default underline because it adds an extra affordance that link buttons navigate. This is especially helpful when a link button appears near prose or other text-heavy content.

Use `underline="never"` only when the surrounding pattern already identifies the control as navigation, such as footer links, navigation lists, toolbar or action groups, and links grouped under a heading such as “Related links.” Avoid removing the underline only to make a link button look quieter, and do not rely on color alone.

## With icon

Use a leading or trailing icon with a label to reinforce navigation intent.

Use the arrow to the right of the text to suggest movement to a new destination.
For link buttons that open in a new tab, rely on the default tear-out icon from the open in a new tab pattern.

## Icon only

Use an icon-only link button when space is limited and the icon has a widely understood meaning related to navigation.

Provide an accessible label with `aria-label` because there is no visible text.
