## Using the component

### When to use

- When the primary action is navigation, such as opening a new page or external site.
- When navigation needs a button-like appearance for visibility and interaction.
- When the navigation stands alone and should stand out from inline text links, such as a primary call to action in a card, banner, or empty state.
- When it sits alongside [`Button`](../button) components and should share their visual weight and alignment.

### When not to use

- When the navigation sits inline within a sentence or among other links and should carry lower visual priority. Instead, use [`Link`](../link).
- For on-page actions like opening a modal, submitting a form, or toggling UI elements. If the action does not navigate the user elsewhere, use [`Button`](../button) instead.

### Choosing sentiment

Use `sentiment="neutral"` for routine navigation. Use `sentiment="accented"` when the destination is a primary or high-priority navigation action.

### Opening in a new tab

Open link buttons in the same tab by default. Use `target="_blank"` only when keeping the current page available helps the user, such as when a link button appears in the middle of a form or multi-step flow.

When linking to third-party content in a new tab, set `rel="noopener"` or `rel="noreferrer"` to protect users in legacy browsers.

### Routing libraries

If your app uses a routing library such as [React Router](https://reactrouter.com/en/main) or [Next.js](https://nextjs.org/docs/app/building-your-application/routing), use the `render` prop to render the routing library’s link component while preserving `LinkButton` styling and behavior. See the [render prop guide](/salt/getting-started/render-prop) for the supported render forms.

## Content

- Keep link button text concise and action-oriented.
- Use text that describes the destination or result, such as “View details” or “Open report”.
- Do not use generic text like “Click here” or “Read more” unless the surrounding context makes the destination clear.

## Import

To import `LinkButton` from the lab Salt package, use:

```js
import { LinkButton } from "@salt-ds/lab";
```
