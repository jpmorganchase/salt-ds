## Best practices

- Use link text that identifies the destination when read out of context. Screen reader users may navigate by a list of links rather than reading the whole page.
- If you add `aria-label` or `aria-labelledby` for extra context, include the visible link text in the accessible name.
- Do not rely on color alone to identify a link. Keep the default underline for inline links in paragraphs, sentences, and table cells. If you remove the underline, provide another visible non-color cue or place the link in a clear navigation pattern.
- When a link contains an icon and text, pass `aria-hidden` to the icon so screen readers do not announce duplicate content.
- When a link contains only an icon, pass an `aria-label` that describes the destination.
- When `target="_blank"` is set, `Link` automatically adds a visual icon and visually hidden text that announces the new tab. Keep the default icon unless your custom content already provides another visible new-tab cue.
