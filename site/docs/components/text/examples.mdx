## Styles

`Text` supports these sets of styles:

- Display
- Headings
- Body
- Label
- Code

These alternative components display text in commonly used styles. Where relevant, use them instead of `Text` to simplify syntax:

- `Display1`
- `Display2`
- `Display3`
- `Display4`
- `H1`
- `H2`
- `H3`
- `H4`
- `Label`
- `Code`
- `TextNotation`
- `TextAction`

## Truncation

The component wraps by default, but you can use the `maxRows` prop to force truncation. Truncation will occur when `maxRows` is greater than 0. If you don't provide a value, the text content will wrap.

### Best practices

Truncated text must comply with [WCAG SC 1.4.4](https://www.w3.org/WAI/WCAG21/Understanding/resize-text.html). If you use truncated text, you must ensure that a screen reader can read the full value. Read the Accessibility section for further guidance.

## Styling

Although we don't encourage it, you may find it necessary to change an element’s mapped styling to another from our typography set. In this case, you'd use the `styleAs` prop.

Using the `styleAs` prop, you can maintain the correct HTML hierarchy and the appropriate visual priority. You can style headings to visually appear as different heading levels, irrespective of the underlying DOM element of a heading on the page.

Set `styleAs` to `inherit` to match the font and color of the parent element. This is useful when you nest `Text` to change the weight of part of the content. The `fontWeight` prop then uses the weights of the closest parent `Text`, or the body text weights if there isn't one.

## Color

Use the `color` prop to adjust the foreground color of any nested text. Use the `primary` color most of the time, the `secondary` color for supporting text or to create visual hierarchy, and `inherit` to inherit text color from the parent element.

Read our [guidance on how to use text color](/salt/foundations/typography#color).

## Font weight

Use the `fontWeight` prop to make text `lighter` or `bolder` than its default weight. Omit the prop to use the default weight. The weights come from the theme and depend on the text style, so `bolder` on a heading is heavier than `bolder` on body text.

To change the weight of part of the text, nest `<Text as="span" styleAs="inherit">` with the `fontWeight` prop. It keeps the parent's text style and color, and uses that style's weights. You can also nest a `<b>` element, which uses the same weight as `bolder`.

```tsx
<H2>
  Quarterly results{" "}
  <Text as="span" styleAs="inherit" fontWeight="lighter">
    (unaudited)
  </Text>
</H2>
```

`fontWeight` and `<b>` change appearance only. Use `<strong>` when the text is important, such as a warning or a key term in a legal disclosure, and `<em>` for stressed emphasis, because these elements convey meaning to assistive technologies. Don't use `<strong>` or `<small>` just to change the weight, and don't wrap the entire content of a heading in `<strong>`.

**Note:** Styling nested `<small>` elements with a lighter weight is deprecated and will be removed in a future major version. Use `fontWeight="lighter"` instead, or nest `<Text as="span" styleAs="inherit" fontWeight="lighter">` for part of the text.

Read our [guidance on how to use font weight](/salt/foundations/typography#font-weight).

## Variant

**Note:** This prop is deprecated. Use the `color` prop instead.

Use the `variant` prop to adjust the foreground color of any nested text. Use the `primary` variant most often, and the `secondary` variant for supporting text or creating a visual hierarchy.

Read our [guidance on how to use text color](/salt/foundations/typography#color).
