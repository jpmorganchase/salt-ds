Read more on our [typography foundation](/salt/foundations/typography) page.

`Text` renders a `div` unless you set `as`, and `H1` to `H4` render headings.
Salt doesn't change the browser's default margins on headings and paragraphs, so
remove them with the
[CSS baseline reset](/salt/getting-started/developing#optional-apply-the-css-baseline-reset)
or your own CSS.

## Import

To import `Text` and related components from the core Salt package, use:

```js
import {
  Text,
  Display1,
  Display2,
  Display3,
  Display4,
  Editorial1,
  Editorial2,
  Editorial3,
  Editorial4,
  Editorial5,
  Editorial6,
  Eyebrow,
  H1,
  H2,
  H3,
  H4,
  Label,
  TextNotation,
  TextAction,
} from "@salt-ds/core";
```
