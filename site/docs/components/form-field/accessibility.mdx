## Best practices

- `FormField` names the form control with `FormFieldLabel` and describes it with `FormFieldHelperText`. Pass `aria-labelledby` and `aria-describedby` to the form control itself, not through props such as `inputProps`. These values are added after the `FormField` ones, so the visible label stays in the accessible name.
- For controls such as `Input`, a rendered `FormFieldLabel` takes precedence over the control's `aria-label`. Composite controls can also retain labels for their individual inputs, such as the start and end labels in `DateInputRange`. Salt logs a warning in development when a consumer-supplied `aria-label` loses words from the computed accessible name. To add words to the name, use `aria-labelledby`. Its text is added after the label, so the name still starts with the visible label text ([WCAG 2.5.3 Label in Name](https://www.w3.org/WAI/WCAG22/Understanding/label-in-name.html)). To add context, use `aria-describedby`.

## Keyboard interactions

All keyboard interactions are supplied by the underlying wrapped components, rather than the `FormField` component.
