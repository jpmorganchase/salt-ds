## Using the component

Within a single segmented button group, only use buttons of the same variant.

### When to use

Use the segmented button group to display a list of actionable buttons, flush with separators between them.

### When not to use

For a persistent selection such as List or Cards, use
[`ToggleButtonGroup`](../toggle-button/usage#view-switching).
`SegmentedButtonGroup` supplies layout for related actions; it does not own a
selected value or selection behavior.

## Import

To import `SegmentedButtonGroup` from the core Salt package, use:

```js
import { SegmentedButtonGroup } from "@salt-ds/core";
```
