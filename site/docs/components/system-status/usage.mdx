## Using the component

The primary purpose of the system status is to provide information and, if necessary, prompt further action.

Always position the system status at the very top of the screen, spanning the full width of the page. See the [placement example](/salt/components/system-status/examples#placement) for more information.

Remove it when:

- The event that triggered it is resolved, such as when service is restored after an outage.
- The information is no longer relevant, such as when scheduled maintenance has finished.

We advise against adding too much content to a system status because of potential color contrast issues. To add actions, such as dismiss, use [`OnSolidButton`](/salt/components/button/examples#on-solid) within `SystemStatusActions`. If you add other components, it's the application team's responsibility to make sure they're accessible.

### When to use

- To inform users about critical system-wide issues, security updates or vulnerabilities that require immediate attention.
- To notify users about new system-wide features or enhancements.
- To alert users about planned maintenance schedules and potential service disruptions affecting the entire platform.

### When not to use

- For inline messaging, or a notification that applies to the user’s current task or workflow. Instead, use [`Banner`](../banner).
- To communicate when content is loading. Instead, use the [content status pattern](/salt/patterns/content-status).
- When the notification requires immediate action and relates to the user’s current task. Instead, use [`Dialog`](../dialog) to interrupt the user's workflow.

## Content

A system status typically has one or two lines of text. Make content short, clear, and concise, allowing users to quickly understand the situation and/or next steps.

If a title is needed, set `fontWeight="bolder"` on it, as shown in the [with title example](/salt/components/system-status/examples#with-title). See the [typography foundation](/salt/foundations/typography/) for more information.

## Import

To import `SystemStatus` and related components from the lab Salt package, use:

```js
import {
  SystemStatus,
  SystemStatusContent,
  SystemStatusActions,
} from "@salt-ds/lab";
```
