## Best practices

Check and test any focusable elements included in the system status content.

When using a system status to alert the user, apply `role="alert"`. When using a system status to notify the user, use the default `role="status"`.

- **Note:** There are known screen reader announcement issues when dynamically inserting content with `role="status"`, which a system status has by default. During your testing, check that a system status added to the page is properly announced using a screen reader.
