## Info

Use the info system status to communicate important updates or new features that do not require immediate action.

An info icon displays alongside a supporting message.

<LivePreview componentName="system-status" exampleName="Info" />

## Error

Use error system status for critical issues that affect the user's ability to access or use the platform. The messaging should tell the user how to resolve the issue. When relevant, add a supporting action to help resolve it. See the [interactive example](#interactive) for how to add actions.

An error icon displays alongside a supporting message.

<LivePreview componentName="system-status" exampleName="Error" />

## Warning

Use warning system status to warn users about potential issues. Warnings announce scheduled outages or events that might impact the product experience, but don't prevent the user from using the application or completing their current workflow.

A warning icon displays alongside a supporting message.

The interactive system status includes actions that let users respond to it.

Use `SystemStatusActions` to add actions such as view status and dismiss. Use [`OnSolidButton`](/salt/components/button/examples#on-solid) for these actions.

## Announced

Announcements for a system status that is added to the page after it loads can be unreliable in screen readers. To make sure it's announced, add an empty live region to the page when it first loads, then add the system status inside it. This also applies to a system status that is dismissed and shown again. The other examples on this page wrap the system status in a live region container in the same way.

Use a container with `role="alert"` for an error system status, or `role="status"` for all other statuses.

<LivePreview componentName="system-status" exampleName="Announced" />

## Placement

System status alerts are displayed at the very top of the screen, extending across the full width of the page.

They are positioned at the same level as the main content, causing any subsequent content to shift accordingly. For example, when a system status is dismissed, the content below it would move up to its original position.
