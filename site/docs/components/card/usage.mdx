## Using the components

Cards may include text, images, or interactive elements. Keep the content aligned with the use case, clear, and easy to read. Avoid overcrowding cards with excessive content or actions.

### When to use

- To group related information with the same visual hierarchy.
- To present a summary of a larger idea.
- **Link cards:** to navigate to more detailed information.
- **Interactable cards:** to perform an action or present options that behave like checkboxes or radio buttons.

### When not to use

- As a background containing other cards. Instead, use [`Panel`](../panel).
- To display sequential information or emphasize ranking. Instead, use [`Static list`](../static-list).
- As a standalone call to action. Instead, use [`Button`](../button).
- For decoration purposes only.

### Card groups

- Group cards in a layout with consistent structure and spacing.
- Avoid duplicating the same image or content across cards.
- Use the same accent placement throughout a group.

### Interactable elements

A static card can contain actionable components such as [buttons](../button) or [links](../link).

Link cards shouldn't contain actionable components (like [buttons](../button) or [links](../link)), as the card itself is the interactive element.

Use an interactable card as a button or within `InteractableCardGroup` as a radio button or checkbox. Don't place other actionable components inside an interactable card.

## Content

- Keep each card focused on one subject.
- Put the most important information first.
- Use a short heading that follows the page's heading hierarchy.
- Keep content order and action placement consistent across cards in a group.
- Allow cards to grow when content changes because of translation, text zoom, or responsive layouts. Don't truncate essential information only to keep cards the same height.

## Import

To import `Card`, its structural sections, `LinkCard`, `InteractableCard`, and `InteractableCardGroup` from the core Salt package, use:

```js
import {
  Card,
  CardContent,
  CardFooter,
  CardHeader,
  InteractableCard,
  InteractableCardGroup,
  LinkCard,
} from "@salt-ds/core";
```
