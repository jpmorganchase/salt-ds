## Using the component

`List` is a composable native list for static rows and rows with persistent actions. It does not manage selection, current state, or keyboard focus.

- `List` provides the `ul` structure. Use `render={<ol />}` when item order is meaningful.
- `ListItem` provides one structural `li` row and lays out direct trailing controls.
- `ListItemContent` contains the row's non-interactive primary content.
- `ListItemTrigger` makes the primary region a native button or link.

Static and actionable rows can appear in the same list.

### Choosing a list component

| Component                          | Use it for                                                   |
| ---------------------------------- | ------------------------------------------------------------ |
| `List`                             | Static content and persistent, independent buttons or links. |
| `ListBox`                          | Choosing one or more values in a form.                       |
| `Menu`                             | A transient composite containing commands.                   |
| `VerticalNavigation` or `MegaMenu` | Application and site navigation systems.                     |

## Composition

### Static content

```tsx
<ListItem>
  <ListItemContent>Quarterly report</ListItemContent>
</ListItem>
```

### Static content with secondary actions

```tsx
<ListItem>
  <ListItemContent>Quarterly report</ListItemContent>
  <Button appearance="transparent" aria-label="Download quarterly report">
    <DownloadIcon aria-hidden />
  </Button>
</ListItem>
```

### Primary button

```tsx
<ListItem>
  <ListItemTrigger onClick={openReport}>
    <ListItemContent>Quarterly report</ListItemContent>
  </ListItemTrigger>
</ListItem>
```

### Primary link

```tsx
<ListItem>
  <ListItemTrigger href="/reports/quarterly">
    <ListItemContent>Quarterly report</ListItemContent>
  </ListItemTrigger>
</ListItem>
```

When combining primary and secondary actions, keep `ListItemTrigger` and each trailing control, or its semantic group, as siblings within `ListItem`. Never put a button, link, checkbox, or other focusable element inside `ListItemTrigger`.

`ListItemContent` renders a `span` so the same component is valid inside static and actionable rows. It supports phrasing, non-interactive content. Configure `Text` and layout primitives within it to use span-safe hosts. Arbitrary block-host content is not supported in the first version.

Leading icons can be ordinary children of `ListItemContent`. The icon, first line of text, and trailing actions stay aligned when the label wraps.

## Button and link behavior

`href` determines the action type. With no `href`, `ListItemTrigger` renders a button and defaults to `type="button"`. With an `href`, it renders an anchor. The button branch supports native `disabled`; links do not have a native disabled state, so `ListItemTrigger` does not provide a fake-disabled link API.

The primary action fills the row, including the empty space around and between direct trailing controls. Each trailing control keeps its own independent hit target.

Use `render` to integrate another link component. Prefer a self-closing JSX render element when props map directly. Do not provide children on the render element unless you intend to override the children of `ListItemTrigger`. Use a callback when a routing library needs `href` mapped to another prop such as `to`.

```tsx
<ListItemTrigger
  href="/reports/quarterly"
  render={({ href, ...props }) => <RouterLink {...props} to={href} />}
>
  <ListItemContent>Quarterly report</ListItemContent>
</ListItemTrigger>
```

For a link with `target="_blank"`, render the Core `Link` component so its external-link treatment remains available without nesting anchors.

```tsx
<ListItemTrigger
  href="https://example.com/reports"
  render={<Link rel="noopener" target="_blank" />}
>
  <ListItemContent>External reports</ListItemContent>
</ListItemTrigger>
```

When multiple trailing controls form a named set, wrap them in an element with `role="group"` and give it an accessible name.

```tsx
<ListItem>
  <ListItemTrigger>
    <ListItemContent>Quarterly report</ListItemContent>
  </ListItemTrigger>
  <span aria-label="Quarterly report actions" role="group">
    <Button aria-label="Download quarterly report" />
    <Button aria-label="Delete quarterly report" />
  </span>
</ListItem>
```

## Containing surfaces

`List` does not own scrolling, dismissal, or focus management. A containing Dialog or Overlay retains those responsibilities, and activating an item does not automatically dismiss it. If an action removes its focused row, the application should move focus to the next logical row, the previous row, or a stable surrounding control.

For navigation, place the list inside a labelled `nav` landmark. Do not change it to menu semantics.

### `ListItemTrigger`

`ListItemTrigger` accepts the native props for the branch selected by `href`. The generated prop reference cannot represent both sides of this discriminated union, so the branch-specific props are summarized here.

| Prop       | Button branch                                            | Link branch                                                                    |
| ---------- | -------------------------------------------------------- | ------------------------------------------------------------------------------ |
| `href`     | Omitted                                                  | Required string                                                                |
| `render`   | Button element or callback receiving native button props | Anchor element or callback receiving native anchor props and a required `href` |
| `type`     | Native button type; defaults to `button`                 | Native anchor media type                                                       |
| `disabled` | Native button disabled state                             | Not available                                                                  |
| `ref`      | `HTMLButtonElement`                                      | `HTMLAnchorElement`                                                            |
