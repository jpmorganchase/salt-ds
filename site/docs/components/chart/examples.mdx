Use a line chart to show changes in data over time.

The small, distinct point markers and labels at the end of each series identify the lines without relying on color.

## Pie chart

Use a pie chart to show proportions of a whole.

Keep the number of slices manageable so their labels stay readable. This example groups smaller categories under "Other" and uses short category names and whole percentages.

<LivePreview componentName="chart" exampleName="PieChart" />

## Donut chart

Use a donut chart to show proportions of a whole, with space in the center to highlight key values or additional information.

As with a pie chart, limit the number of slices and use short labels. This example uses the same six-category revenue breakdown.

A donut chart is a variation of the pie chart, with the `plotOptions.pie.innerSize` set to less than `100%` within the `Options` object.

### Best practices

An `innerSize` value of `80%` is recommended for a good default visual balance.

## Stacked bar chart

Use a stacked bar chart to compare part-to-whole relationships across categories. Each bar shows the total, with segments representing series values.

A stacked bar chart is a variation of the bar chart, with the `plotOptions.series.stacking` set to `normal` within the `Options` object.

The abbreviated labels inside each segment and the left-to-right order explained below the chart identify the stacks without relying on color.

<LivePreview componentName="chart" exampleName="StackedBarChart" />

## Candlestick chart

Use a candlestick chart to display price movements over time, showing open, high, low, and close values for each period. This chart type is commonly used for financial data visualization.

In this `candlestick` example, hollow bodies mean the close is above the open, and filled bodies mean the close is below the open. The visible key updates when pattern fills are enabled. Highcharts also has a separate [hollow candlestick chart](https://www.highcharts.com/docs/stock/hollow-candlestick-chart), which uses color to compare the close with the previous period's close.

<Callout title="Note">
  To use the candlestick chart, import the Highcharts `stock` module and use it
  to wrap the `Highcharts` object as shown in the example.
</Callout>

<LivePreview componentName="chart" exampleName="CandlestickChart" />

## Box plot chart

Use a box plot chart to show the distribution of data across different categories, displaying minimum, first quartile, median, third quartile, and maximum values.

### Best practices

Allow Highcharts to calculate box widths from the available space rather than fixing `pointWidth`, especially when multiple series share each category. Use `maxPointWidth` to cap their width on larger screens without forcing it on smaller ones.

The key below the example explains the left-to-right order within each quarter when both regions are visible.

<Callout title="Note">
  To use the box plot chart, ensure you import the Highcharts `highcharts-more`
  module and use it to wrap the `Highcharts` object as shown in the example
  below.
</Callout>

## Bubble chart

Use a bubble chart to show the relationship between two variables, with a third variable represented by the size of each bubble.
Salt gives bubble labels a contrasting text outline so they remain readable where they cross the edge of a bubble.

The key below the plot groups assets by class. On wide charts, each bubble shows its asset name. On narrow charts, each bubble shows a number that matches its entry in the key. The tooltip gives the full asset name and values at either width.

<Callout title="Note">
  To use the bubble chart, import the Highcharts `highcharts-more` module and
  use it to wrap the `Highcharts` object as shown in the example.
</Callout>

<LivePreview componentName="chart" exampleName="BubbleChart" />

## Heatmap chart

Use a heatmap chart to compare values across two categorical axes, with color
used to show magnitude. To ensure accessible presentation, data labels have borders by default.

For heatmap variations such as discrete range legends or two-color banding, see
[Color axis](./usage#color-axis) in the usage guide.

<Callout title="Note">
  To use the heatmap chart, import the Highcharts `heatmap` module and use it to
  wrap the `Highcharts` object as shown in the example.
