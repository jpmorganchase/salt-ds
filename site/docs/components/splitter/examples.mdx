<ReactResizablePanelsThemeProvider>

## Default

Applies the default look when applying the Salt theme.
By default, the resize handles are transparent, allowing the background color of the parent container to be visible through them.

  componentName="react-resizable-panels-theme"
  exampleName="Default"
/>
## Variants

Both separators and resizable panels offer three background variants.

**For the Panel Component:**
Use the following class names to apply the desired background variant:

- `resizable-panel-salt-variant-primary`
- `resizable-panel-salt-variant-secondary`
- `resizable-panel-salt-variant-tertiary`

**For the Separator Component:**
Apply these class names to select the appropriate background variant:

- `resize-handle-salt-variant-primary`
- `resize-handle-salt-variant-secondary`
- `resize-handle-salt-variant-tertiary`

<LivePreview
  componentName="react-resizable-panels-theme"

/>
## Border

There are 4 border directions in the Salt React Resizable Panels theme: `top`, `bottom`, `left` and `right`. By default, `Separator` components render with no borders. To add borders, apply any of the following class names to `Separator`:

For a `Group` with `orientation="vertical"`:

- `resize-handle-salt-border-top`
- `resize-handle-salt-border-bottom`

<LivePreview
  componentName="react-resizable-panels-theme"
  exampleName="Vertical"
/>
For a `Group` with `orientation="horizontal"`:

- `resize-handle-salt-border-left`
- `resize-handle-salt-border-right`
