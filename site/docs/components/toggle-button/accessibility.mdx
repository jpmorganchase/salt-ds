## Best practices

- When a toggle button has both an icon and text, use `aria-hidden` on the icon so that screen readers don't announce its text.
- When a toggle button has an icon only and no text, pass an `aria-label` to the button that describes its purpose.

## Keyboard interactions

Outside a toolbar, arrow keys move focus and select the next or previous enabled
option. In a toolbar, arrow keys move focus without changing selection; Space or
Enter selects the focused option. Horizontal arrows continue to adjacent toolbar
controls at a group boundary, and Tab leaves the toolbar. Read-only groups allow
focus movement without changing selection.

<KeyboardControls>
<KeyboardControl keyOrCombos="Tab">

- Tab moves focus into the toggle button group. Focus is set to the active button.
- If focus is inside the toggle button group, Tab moves focus out of the toggle button group. Focus is set to the next component in the tab order.

</KeyboardControl>
<KeyboardControl keyOrCombos="Space / Enter">

- When focus is on the toggle button and the button is inactive, this action activates the button.
- If focus is on an active button, this actions keeps the button active.

</KeyboardControl>
<KeyboardControl keyOrCombos="Shift + Tab">

- If focus is inside the toggle button group, this action moves focus out of the component. Focus is set to the previous component in the tab order.
- If focus is below the toggle button group, this action move focus into the toggle button group. Focus is set to the active button.

</KeyboardControl>
<KeyboardControl keyOrCombos="Right arrow / Down arrow">

- This action moves focus to the next enabled toggle button in the group and selects it, except in a toolbar or a read-only group.
- Outside a toolbar, if focus is on the last enabled toggle button, this action wraps focus to the first enabled toggle button.

</KeyboardControl>
<KeyboardControl keyOrCombos="Left arrow / Up arrow">

- This action moves focus to the previous enabled toggle button in the group and selects it, except in a toolbar or a read-only group.
- Outside a toolbar, if focus is on the first enabled toggle button, this action wraps focus to the last enabled toggle button.

</KeyboardControl>
</KeyboardControls>
