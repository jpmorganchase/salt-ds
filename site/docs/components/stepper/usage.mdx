| Aspect     | Step count  | Space available    | Layout        | Expandable | Title               | Descriptions |
| ---------- | ----------- | ------------------ | ------------- | ---------- | ------------------- | ------------ |
| Horizontal | 3-6 optimal | Wide layouts       | Left-to-right | No         | Concise (1-2 words) | Below steps  |
| Vertical   | Any count   | Normal/Constrained | Top-to-bottom | Yes        | Can be long         | Beside steps |

## When to use

- Horizontal stepper: for wide layouts and desktop applications where you want to show all steps simultaneously and let users scan progress at a glance; best with 3–6 steps and no nested substeps.
- Vertical stepper: for step-by-step guided experiences that need detailed, multi-line descriptions per step, or expandable (accordion-style) step content; works well with longer label text.

## When not to use

- Horizontal stepper
  - Avoid in sidebars/panels or narrow containers; it should only be placed above form/page content, not within constrained-width regions.
- Vertical stepper
  - Avoid when horizontal space is abundant and steps have minimal content; the extra vertical real estate isn't justified for short, simple step sequences. It should ideally be used in a 2 column page layout

## Content

- Pass plain text to `label` and `description`. They're combined into the text that screen readers announce, so other content, such as an element, isn't announced correctly.
- Labels and descriptions wrap and never truncate.

## Import

To import `Stepper` and `Step` from the core Salt package, use:

```js
import { Stepper, Step } from "@salt-ds/core";
```
