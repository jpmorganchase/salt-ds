## Using the components

### When to use

- When users need to choose one value from a small, mutually exclusive set of options that should remain visible together.

### When not to use

- When multiple independent choices are allowed. Instead, use [`CheckboxGroup`](../checkbox).
- When a selectable list is a better fit, the options should be in a popup, or typing would help users find an option. See [Choosing a selection control](../list-box/usage#choosing-a-selection-control) for `ListBox`, `Dropdown` and `ComboBox`.
- For an on/off setting that takes effect immediately. Instead, use [`Switch`](../switch).
