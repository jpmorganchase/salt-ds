## Keyboard interactions

<KeyboardControls>
<KeyboardControl keyOrCombos="Enter / Space">

- If focus is on the trigger element, this action activates the element and opens the drawer. Focus doesn't leave the drawer.
- If focus is on close button, this action closes the drawer. Focus returns to the trigger element.
- If focus is on a content element configured to close the drawer when activated, such as a _Submit_ button, this action closes the drawer.

</KeyboardControl>
<KeyboardControl keyOrCombos="Tab">

- Tab moves focus through focusable content elements in the drawer. Focus doesn't leave the drawer.

</KeyboardControl>
<KeyboardControl keyOrCombos="Shift + Tab">

- This action moves focus to previous focusable content element in the drawer. Focus doesn't leave the drawer.

</KeyboardControl>
<KeyboardControl keyOrCombos="Escape">

- Escape closes the drawer and returns focus to the trigger element.

</KeyboardControl>
</KeyboardControls>

## Resize handle

When the `resizable` prop is set, the drawer renders a resize handle on its inner edge. The handle has a role of `separator`, joins the tab order after the drawer's content, and reports the drawer's current size and limits through `aria-valuenow`, `aria-valuemin` and `aria-valuemax`.

<KeyboardControls>
<KeyboardControl keyOrCombos="Left / Right">

- When focus is on the resize handle of a left or right drawer, this action resizes the drawer by a small step.

</KeyboardControl>
<KeyboardControl keyOrCombos="Up / Down">

- When focus is on the resize handle of a top or bottom drawer, this action resizes the drawer by a small step.

</KeyboardControl>
<KeyboardControl keyOrCombos="Shift + Arrow">

- This action resizes the drawer by a larger step.

</KeyboardControl>
<KeyboardControl keyOrCombos="Home">

- This action resizes the drawer to its minimum size.

</KeyboardControl>
<KeyboardControl keyOrCombos="End">

- This action resizes the drawer to its maximum size.

</KeyboardControl>
</KeyboardControls>
