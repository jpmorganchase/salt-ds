## Interactions

- Users can resize a resizable drawer by dragging its inner edge.
- Users can also resize it without dragging: they click the edge, then click the new position for it. A guide line shows the new position until the second click.
- When the resize handle has focus, users can resize the drawer with the keyboard.

## Keyboard interactions

<KeyboardControls>
<KeyboardControl keyOrCombos="Enter / Space">

- If focus is on the trigger element, this action activates the element and opens the drawer. Focus doesn't leave the drawer.
- If focus is on close button, this action closes the drawer. Focus returns to the trigger element.
- If focus is on a content element configured to close the drawer when activated, such as a _Submit_ button, this action closes the drawer.

</KeyboardControl>
<KeyboardControl keyOrCombos="Tab">

- Tab moves focus through focusable content elements in the drawer. Focus doesn't leave the drawer.

</KeyboardControl>
<KeyboardControl keyOrCombos="Shift + Tab">

- This action moves focus to previous focusable content element in the drawer. Focus doesn't leave the drawer.

</KeyboardControl>
<KeyboardControl keyOrCombos="Escape">

- Escape closes the drawer and returns focus to the trigger element.
- If the user is placing the edge of a resizable drawer by click, Escape cancels the resize instead and keeps the drawer open.

</KeyboardControl>
</KeyboardControls>

### Resizable drawer

When the resize handle of a resizable drawer has focus:

<KeyboardControls>
<KeyboardControl keyOrCombos="Left arrow / Right arrow">

- For left and right drawers, moves the edge by a small step.

</KeyboardControl>
<KeyboardControl keyOrCombos="Up arrow / Down arrow">

- For top and bottom drawers, moves the edge by a small step.

</KeyboardControl>
<KeyboardControl keyOrCombos="Home">

- Shrinks the drawer to its minimum size.

</KeyboardControl>
<KeyboardControl keyOrCombos="End">

- Grows the drawer to its maximum size.

</KeyboardControl>
<KeyboardControl keyOrCombos="Enter">

- Shrinks the drawer to its minimum size, or restores its previous size.

</KeyboardControl>
</KeyboardControls>
