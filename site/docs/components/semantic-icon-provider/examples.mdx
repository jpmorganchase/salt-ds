## Default

Salt components use their default semantic icons without configuration. Wrap the relevant application or section in `SemanticIconProvider` when you need to customize those roles.

<LivePreview componentName="semantic-icon-provider" exampleName="Default" />

## Icon map

Pass a partial `iconMap` to replace selected roles. Unspecified roles retain the Salt defaults. Choose replacements with the same meaning and review them beside related states.
