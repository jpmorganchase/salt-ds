## Default

A parent-child layout displays the parent component to the left and child component to the right.

<LivePreview componentName="parent-child-layout" exampleName="Default" />

## Collapsed

The layout collapses at `collapseAtBreakpoint` and every smaller breakpoint: only one region is visible, filling the width of the parent, and `visibleView` chooses which. With the default breakpoints, the default `"sm"` collapses the layout below 960 pixels and shows the regions side by side from `md` up.

<LivePreview componentName="parent-child-layout" exampleName="Collapsed" />
