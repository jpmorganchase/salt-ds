## Using the package

### When to use

- When you want to use the Salt theme with AG Grid for complex or high-volume data.
- When you need advanced grid behaviors such as frozen columns, editable cells, custom cell renderers, sorting, filtering, or selection.

### When not to use

- When you need simple tabular structure, including application-filtered rows or ordinary links and actions in cells, use [Table](../table).
- When you do not need AG Grid's advanced grid behaviors, use a simpler presentation component instead.

## Set up

The Salt AG Grid theme is a CSS theme. Apply it with a container class name; its mode and default sizes come from the nearest `SaltProvider`. The theme styles AG Grid; AG Grid and your application remain responsible for grid behavior and data.

For AG Grid v33 and later, this is the smallest setup using Community modules:

```tsx
import { AllCommunityModule, ModuleRegistry } from "ag-grid-community";
import { AgGridReact } from "ag-grid-react";
import "ag-grid-community/styles/ag-grid.css";
import "@salt-ds/ag-grid-theme/salt-ag-theme.css";

ModuleRegistry.registerModules([AllCommunityModule]);

<div className="ag-theme-salt" style={{ height: 400 }}>
  <AgGridReact theme="legacy" rowData={rowData} columnDefs={columnDefs} />
</div>;
```

Install the packages and review the configuration details below before using the example in your application.

### 1. Install the packages

Install the theme with AG Grid's Community packages:

```sh
npm install @salt-ds/ag-grid-theme ag-grid-community ag-grid-react
```

If you have an AG Grid Enterprise license, also install `ag-grid-enterprise`.

### 2. Register AG Grid's modules

AG Grid v33 and later need the modules a grid uses registered before the grid is created. Register them once, where your application starts.

With AG Grid Community:

```js
import { AllCommunityModule, ModuleRegistry } from "ag-grid-community";

ModuleRegistry.registerModules([AllCommunityModule]);
```

With AG Grid Enterprise:

```js
import { ModuleRegistry } from "ag-grid-community";
import { AllEnterpriseModule } from "ag-grid-enterprise";

ModuleRegistry.registerModules([AllEnterpriseModule]);
```

<Callout title="Enterprise features">

Features marked as AG Grid Enterprise features in the [examples](./examples), such as the Set filter (`agSetColumnFilter`), cell selection, row grouping and the status bar, need `ag-grid-enterprise` and a license. With only `ag-grid-community`, a grid that uses one logs an AG Grid error that the feature's module isn't registered (error #200). With Community, filter with `agTextColumnFilter`, `agNumberColumnFilter` or `agDateColumnFilter`.

</Callout>

### 3. Import the CSS

```js
import "ag-grid-community/styles/ag-grid.css";
import "@salt-ds/ag-grid-theme/salt-ag-theme.css";
```

### 4. Apply the theme

Put the grid in a container with the `ag-theme-salt` class name, and set `theme="legacy"` on the grid:

```jsx
<div className="ag-theme-salt" style={{ height: 400 }}>
  <AgGridReact theme="legacy" rowData={rowData} columnDefs={columnDefs} />
</div>
```

- **`theme="legacy"`:** from v33, AG Grid styles grids with its Theming API unless told otherwise, and reports an error when that's used with a CSS theme such as Salt's (error #239). Set `theme="legacy"` on each grid, or once for every grid with `provideGlobalGridOptions({ theme: "legacy" })`. See AG Grid's [guide to legacy themes](https://www.ag-grid.com/javascript-data-grid/theming-migration/#continue-with-legacy-themes).
- **Height:** AG Grid fills its container, so give the container a height, or set `domLayout="autoHeight"` on the grid to size it to its rows.
- **Mode and density:** the theme follows the nearest `SaltProvider`, as other Salt components do. Leave `rowHeight` and `headerHeight` unset to use the theme's sizes, except in the cases described in [Density](#density).

## Density

**On AG Grid v36.3 and later, client-side grids follow the density of the nearest `SaltProvider` through CSS, including columns with `autoHeight`.** Leave `rowHeight` and `headerHeight` unset to use the sizes supplied by the theme. The [Auto-height cells](./examples#auto-height-cells) example includes wrapped text, empty cells and fixed-height renderers.

Column `autoHeight` sizes each row to its content. It is separate from `domLayout="autoHeight"`, which sizes the grid container to its rows.

The versions below support automatic density changes when row sizing comes from the theme:

| Grid configuration                                    | Automatic density changes from |
| ----------------------------------------------------- | ------------------------------ |
| Client-side, without `autoHeight` columns             | v33                            |
| Infinite or viewport                                  | v36.2                          |
| Server-side, without `autoHeight` columns             | v36.2                          |
| Client-side or server-side, with `autoHeight` columns | v36.3                          |

- **Uniform row heights on v33 to v36.1:** infinite, viewport and server-side grids need a reactive `rowHeight` to resize existing rows when density changes. Derive it from `useDensity()`. The [Infinite scroll](./examples#infinite-scroll) example retains this approach for compatibility with these versions.
- **Auto-height columns before v36.3:** client-side and server-side grids may retain a previous row height when their auto-height content does not resize. Use v36.3 or later for automatic density changes in grids that mix wrapped, empty and fixed-height content.
- **AG Grid v28 to v32:** these versions read row sizes when the grid is created. If density changes while a grid is visible, remount it with a key such as `key={density}`.

### Size reference

Rows and the header use these sizes:

| Density          | Row height | Header height |
| ---------------- | ---------- | ------------- |
| High             | 25px       | 24px          |
| Medium           | 37px       | 36px          |
| Low              | 49px       | 48px          |
| Touch and mobile | 61px       | 60px          |

A row's height includes the border below it.

### HD Compact (opt-in)

For specialized, high-density grids, use `ag-theme-salt-compact` instead of `ag-theme-salt` for 21px rows and a 20px header. **HD Compact is not a Salt density:** other Salt components and patterns do not support it. Prefer the standard theme unless your grid needs the extra density.

The compact class applies compact sizing wherever it is used, including outside high density, for compatibility. If your application switches density dynamically, apply the compact class only in high density and fall back to `ag-theme-salt` otherwise. The [HD Compact example](./examples#hd-compact) demonstrates this; you do not need `useDensity()` solely to use a static compact grid.

## Customization

Use AG Grid's configuration APIs for sorting, filtering, editing, selection and data behavior. Use the documented Salt theme classes below for appearance. Avoid depending on AG Grid's internal DOM selectors: those can change between AG Grid versions.

The theme's visual options are class names:

| Class name                                                                                        | Where                                      | What it does                                                                                                                                                             |
| ------------------------------------------------------------------------------------------------- | ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `ag-theme-salt`                                                                                   | Container                                  | Applies the theme.                                                                                                                                                       |
| `ag-theme-salt-compact`                                                                           | Container, in place of `ag-theme-salt`     | Applies the theme with HD Compact sizes, intended for high density.                                                                                                      |
| `ag-theme-salt-variant-secondary`, `ag-theme-salt-variant-tertiary`                               | Container, with the theme class            | Uses the secondary or tertiary background. See [Variants](./examples#variants).                                                                                          |
| `ag-theme-salt-variant-zebra`                                                                     | Container, with the theme class            | Alternates row backgrounds. See [Zebra](./examples#zebra).                                                                                                               |
| `ag-theme-salt-header-primary`, `ag-theme-salt-header-secondary`, `ag-theme-salt-header-tertiary` | Container, with the theme class            | Sets the header's background. See [Header variant](./examples#header-variant).                                                                                           |
| `editable-cell`                                                                                   | A column's `cellClass`                     | Styles editable cells, and AG Grid's provided cell editors in them. See [Cell editors](./examples#cell-editors).                                                         |
| `numeric-cell`                                                                                    | A column's `cellClass`                     | Right-aligns values, with validation states and edited values to match. AG Grid's `rightAligned` and `numericColumn` column types do the same and also align the header. |
| `warning-cell`, `success-cell`, `error-cell`                                                      | A column's `cellClass` or `cellClassRules` | Shows a validation state on an editable cell. See [Cell validation](./examples#cell-validation).                                                                         |
| `warning-row`, `success-row`, `error-row`                                                         | The grid's `rowClass` or `rowClassRules`   | Shows a validation state on a row. See [Row validation](./examples#row-validation).                                                                                      |

For a numeric column, set AG Grid's `type: "rightAligned"` or `type: "numericColumn"`, which right-aligns its header and values. The theme lines up validation states and edited values with them, as it does for `numeric-cell`.

## Migration and compatibility

The theme supports AG Grid v28 to v36.

- **Existing theme classes:** `ag-theme-salt-light`, `ag-theme-salt-dark`, `ag-theme-salt-compact-light` and `ag-theme-salt-compact-dark` continue to work. Prefer `ag-theme-salt` or `ag-theme-salt-compact` for new integrations; mode comes from the nearest `SaltProvider`.
- **Explicit heights:** on AG Grid v36.3 and later, remove `rowHeight` and `headerHeight` if they only reproduce the theme's sizes, including for grids with `autoHeight` columns. For older versions, follow the row-model and version guidance in [Density](#density).
- **v28 to v32:** skip module registration and `theme="legacy"`; remount the grid if density changes while it is visible.
- **v33 to v36:** register the required modules and use `theme="legacy"` as shown above.
