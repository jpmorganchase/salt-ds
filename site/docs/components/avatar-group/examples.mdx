## Default

`AvatarGroup` represents a group of related users, entities or objects in a compact space, using a horizontal stack of overlapping avatars.

Compose the avatars you want to display and, when members are hidden, add an `AvatarGroupCount` (e.g., “+N” where N is the number of hidden members) as the last child to indicate the additional members.

<LivePreview componentName="avatar-group" exampleName="Default" />

## Entity avatars

An `AvatarGroup` can represent non-person entities, such as teams, businesses or accounts. Set `kind="entity"` on each `Avatar` to display it as a square, and on the `AvatarGroupCount` so that it matches the avatars it summarizes.

<LivePreview componentName="avatar-group" exampleName="Entity" />

## Visible avatars

Choose how many avatars to display based on the space available and how recognizable the individual members need to be. Update the `AvatarGroupCount` to match the number of members you don’t display.

Display at least two avatars in an `AvatarGroup`; if only one fits, use a single [Avatar](/salt/components/avatar) instead.

<LivePreview componentName="avatar-group" exampleName="Visible" />

## Interactive

`AvatarGroup` can be made interactive using the `render` prop. Props defined on the JSX element will be merged with props from the component.

Common interactive use cases include:

- Revealing the full list of members when an avatar group is activated.
- Opening a menu with group-related actions.

<LivePreview componentName="avatar-group" exampleName="Interactive" />

### Best practices

Ensure the avatar group has a meaningful accessible name so screen reader users understand what action will occur.
