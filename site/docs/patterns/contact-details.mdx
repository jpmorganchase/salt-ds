## When to use

Use this pattern to:
- Provide details and direct channels of communication for sales or support purposes.
- Display contact information in a directory or CRM (Customer Relationship Management) system.
- Allow users to populate form fields in a workflow with details from a list of contacts, e.g., client contact selection for a ticket.

<GuidanceCallout type="positive" customPillText="Best practices">
Consider a data grid when you need to display many contacts with a standardized set of contact information.
</GuidanceCallout>

## How to build

### Anatomy

The contact details pattern comprises an avatar and text elements:

1. **Avatar**: A visual representation of the contact that provides a point of reference at glance.
2. **Header**: Contains the name of the contact. Optionally, use text to display further information such as company names or company ID.
3. **Additional details**: Relevant meta data, e.g., role, location, phone number or email. You can define the details as links, making them interactive, to enable immediate communication to a contact from within your application.

<GuidanceCallout type="positive" customPillText="Best practices">
Keep label lengths similar to ensure close proximity to their respective values. If you’re displaying supplementary details, we recommend that you left align their labels.
</GuidanceCallout>

### Layout

- Use [`StackLayout`](/salt/components/layouts/stack-layout) with `direction="row"` and `gap={2}` (`--salt-spacing-200`) to display the avatar beside the text elements.
- Stack the header above the additional details in a `StackLayout` with `direction="column"` and `gap={1}` (`--salt-spacing-100`).
- In the header, use a column `StackLayout` with `gap={0.5}` (`--salt-spacing-50`) between the name and the further information. Display the name with the H2 text style, and the company name and ID with the H4 text style.
- Display the additional details as a column of labels beside a column of values, in a row `StackLayout` with `gap={2}`. Each column is a `StackLayout` with `gap={0.5}`. Labels use the Body text style in the secondary color, and values use Body.

## Quick actions

You can define quick actions, one-click shortcuts to specific functions or features. This can include starting a new email in Outlook, or calling a contact in Zoom.

Ensure that quick action buttons have a tooltip displayed as per the [icon only button best practices](https://www.saltdesignsystem.com/salt/components/button/examples#icon-only).

For layout guidance, refer to the [button bar pattern](/salt/patterns/button-bar). In the example below, the quick actions are transparent icon-only buttons in a row `StackLayout` with `gap={1}`, below the header.

## Collapsible

If you’re displaying supplementary details, you can configure them to be collapsible.

- Place the quick actions and the collapse button in a [`SplitLayout`](/salt/components/layouts/split-layout), with the actions as the `startItem` and the collapse button as the `endItem`.
- Separate the collapsible details from the actions with a top border that uses `--salt-separable-primary-borderColor`, and keep `gap={1}` (`--salt-spacing-100`) in the column `StackLayout` that holds the header, actions and details.

<GuidanceCallout type="positive" customPillText="Best practices">
Consider making supplementary details collapsible when they contain secondary information, and don’t need to be always on display.
</GuidanceCallout>

## List version

The list version allows you to display a snapshot of key details. It’s ideal when you have restricted real estate, such as in a client picker dropdown menu or a contact directory list.

To show as many options as possible, we recommend you keep data points to no more than one line. Prioritize the most important values. 

The link function won't be able to be applied to the text content (e.g. email or phone number) as it is an list item that users select as a whole option from the dropdown.

- Place the avatar beside the text with `gap={1}` (`--salt-spacing-100`).
- Use a column `StackLayout` with `gap={0.5}` (`--salt-spacing-50`) between the name and the details below it. The name uses the Body text style with the bolder weight.
- Display the details underneath the header in a row with `gap={3}` (`--salt-spacing-300`) between them, each an icon beside its value.
