How much of the icon box does the glyph fill?

Original and redrawn icons occupy the same display box. Measurements follow the painted glyph, including strokes and points. The original viewBox and original fixed line weight are preserved. Enlarged overlays reveal changes in extent and position.

This measures geometry, not perceived size or recognition. No artwork has been resized by this report. Default comparison: 12px at the high/medium stroke; select 16px for the touch/mobile stroke.

Cyan = original · Magenta = redraw in the enlarged overlay. Width × height is the painted extent in CSS pixels. Ink area measures coverage separately; it is not a size score.
