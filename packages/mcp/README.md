# Unreleased Salt AI tooling

This workspace contains private implementation experiments for possible Salt
developer tooling. It has not been released and is not a supported consumer
package.

Do not install `@salt-ds/mcp`, depend on its current commands or APIs, or treat
its repository implementation as a compatibility commitment. Public guidance
will be added only after a delivery architecture and supported package surface
have shipped.

For supported Salt application setup, use the
[Developing with Salt](https://www.saltdesignsystem.com/salt/getting-started/developing)
guide and the ordinary public package READMEs.
